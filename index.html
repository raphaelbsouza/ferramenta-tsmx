Renovação de certificados dos gateways

O que solicitar ao cliente e como proceder para atualizar o certificado de cada banco integrado ao SGP.

!

Antes de começar: o que é o Certificado A1

O Certificado A1 não é gerado pelo banco. Ele é emitido por uma Autoridade Certificadora (geralmente quem providencia é a contabilidade) e é o mesmo certificado usado na emissão de Nota Fiscal. Solicite sempre o arquivo atualizado junto com a senha.

Procedimento por gateway

Agrupados pelo tipo de processo

Grupo 1 · Certificado A1 + Portal do Desenvolvedor + AnyDesk

Bradesco

Certificado A1

Solicitar ao cliente

  • Certificado A1 da empresa atualizado, com senha
  • Acesso ao Portal do Desenvolvedor Bradesco
  • Acesso remoto (AnyDesk)

Santander

Certificado A1

Solicitar ao cliente

  • Certificado A1 da empresa atualizado, com senha
  • Acesso ao Portal do Desenvolvedor Santander
  • Acesso remoto (AnyDesk)

Sicoob

Certificado A1 · validação com boleto

Solicitar ao cliente

  • Certificado A1 da empresa atualizado, com senha
  • Acesso ao Portal do Desenvolvedor Sicoob
  • Acesso remoto (AnyDesk)

Procedimento

  1. Atualizar o certificado no gateway do SGP
  2. Gerar 1 boleto de teste
  3. Se retornar Unauthorized, transferir para a Fila de Integrações
AtençãoErro Unauthorized após a troca: encaminhar para a Fila de Integrações.
Grupo 2 · Somente no SGP

Banco do Brasil

Certificado A1

Solicitar ao cliente

  • Certificado A1 da empresa atualizado, com senha

Procedimento

  1. Trocar o certificado no gateway do SGP
SimplesNão é necessário atualizar no banco nem acesso remoto.
Grupo 3 · Processos específicos (sem Certificado A1)

Sicredi PIX

ID de Renovação / Adesão

Solicitar ao cliente

  • ID de Renovação da API PIX (solicitado pelo cliente ao Sicredi)
  • Acesso ao portal Developers Sicredi
  • Acesso remoto (AnyDesk)

Procedimento

  1. Cliente solicita ao Sicredi o ID de Renovação da API PIX
  2. Cliente retorna o contato com o ID de Renovação ou Adesão
  3. Acessar o portal Developers Sicredi via AnyDesk e concluir

Gerencianet / Efí PIX

Certificado gerado na conta Efí

Solicitar ao cliente

  • Acesso à conta Efí / Gerencianet
  • Acesso remoto (AnyDesk)

Procedimento

  1. Acessar a conta Efí do cliente
  2. Gerar o novo certificado na própria plataforma
InformaçãoAqui o certificado é gerado na Efí, não é o A1 da contabilidade.

Banco Inter

Certificado gerado na plataforma do Inter

Solicitar ao cliente

  • Acesso à conta do Banco Inter
  • Acesso remoto (AnyDesk)

Procedimento

  1. Acessar a conta Inter do cliente via AnyDesk
  2. Gerar o novo certificado na própria plataforma do Inter
InformaçãoNão é Certificado A1: o certificado é gerado na plataforma do Inter.

Itaú

O procedimento depende da validade do certificado atual
Até 30 dias para expirar

Conseguimos renovar o certificado usando o próprio certificado que ainda está em uso (não expirado).

Já expirado

O cliente deve contatar o Gerente Itaú e solicitar um novo Token (Bearer) para o client-id já utilizado.

AtençãoSempre que possível, renove antes do vencimento: evita depender do gerente do banco.
